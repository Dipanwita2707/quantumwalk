`quantum-explorer-v1.png` is a generated, generic illustrated explorer used in the dashboard profile panel. It is decorative and does not depict the signed-in user. Generated on 29 October 2026 in the reference's navy, violet and cyan style. Learning-path thumbnails reuse the concept artwork below; they are not simulation outputs.

`quantum-universe-v1.png` and `quantum-quest-v1.png` were generated for QuantumWalk on 28 October 2026 using the image-generation tool. Prompts requested the reference showcase's navy, violet and cyan illustration style, with no embedded text, logos or UI controls.

The images are decorative concept art. They do not represent measured results, electron trajectories or a scientific simulation. Scientific plots and detector counts are generated from the model/API outputs instead. Next.js Image serves responsive versions of the artwork.
