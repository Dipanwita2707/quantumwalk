# Project-local Codex resources

Use `AGENTS.md` for essential instructions that should always apply. Use `.agents/skills/` for task-specific workflows and `.codex/prompts/` for reusable task templates.

Do not copy all skill contents into every prompt. Ask Codex to use the one or two relevant skills for the current task.

`config.toml.example` is deliberately not a ready-to-replace global configuration. Codex settings vary by version and runtime.
